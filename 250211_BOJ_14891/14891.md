# BOJ 14891 문제 풀이
## 기본 정보
1. 반시계 방향 회전: -1
    - 반시계 방향으로 회전하면 12시 방향을 가리키던 `index`는 `index + 1`됨   
    ex) 원래 0이면 1,  원래 7이면 0
        - `index = (index - dir) % 8`

<br>

2. 시계 방향 회전: 1
    - 시계 방향으로 회전하면 12시 방향을 가리키던 `index`는 `index - 1`됨   
    ex) 원래 0이면 7, 원래 2이면 1
        - `index = (index - dir) % 8`

<br>

3. `Left`, `Right` 정보
    - `Left`는 9시 방향, 12시 방향 기준 2칸 왼쪽 (6칸 오른쪽)
    `left` = `(index - 2 + 8) % 8` = `(index + 6) % 8`
    - `Right`는 3시 방향, 12시 방향 기준 2칸 오른쪽
    `right` = `(index + 2) % 8`

## 풀이
1. 돌아가는 바퀴들 탐색 <- 좌측, 우측 따로 진행
    - 탐색할 때마다 `dir` = `-dir` 해주면서 마지막 톱니 바퀴의 회전 방향 파악

<br>

2. 역순으로 돌아오며 회전시킴
    - 회전의 의미는 12시 방향을 가리키는 index를 변경시켜 주는 것
    - 회전할 때마다 `dir` = `-dir` 해주며 `시계 / 반시계` 바꿔줌

<br>

3. 마지막에 처음 돌린 톱니 바퀴 회전시킴
