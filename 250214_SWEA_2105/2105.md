# 🏡 디저트 카페

## 📌 유형
- ✅ DFS(재귀)
- ✅ 백트래킹
- ✅ 가지치기

---

## 🔍 고려사항

### 🔹 대각선 순회
- 방향: 우하 ➝ 좌하 ➝ 좌상 ➝ 우상
- `dx = [1, 1, -1, -1]`
- `dy = [1, -1, -1, 1]`
- **순서 지켜서 탐색**

### 🔹 가지치기
- 커브를 **두 번** 돌면 사각형의 두 변이 완성됨  
- 즉, 사각형이 완성되면 **현재까지 탐색한 길이 × 2가 전체 길이**  
- `현재까지의 길이 × 2 < 현재 최대 길이` → **가망 없음 → return** 🚀
