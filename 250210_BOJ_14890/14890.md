# 길을 만들 수 있는 조건 검사

## 가로줄 검사
- 한 행씩 검사를 진행
- 이때 **왼쪽에서 출발할 때와 오른쪽에서 출발할 때**가 모두 길을 만들 수 있어야 최종적으로 길을 만들 수 있다고 판단


## 세로줄 검사
- **전치 행렬**로 배열을 뒤집어 행과 열을 바꾼 후, 가로줄 검사와 동일한 방식으로 검사 진행
- 마찬가지로 **왼쪽과 오른쪽에서 출발할 때의 경우를 모두 검사**한 후, 두 경우 모두 길을 만들 수 있을 때만 `res += 1` 증가


## `solve()` 함수 로직
한 행에 대해 한 방향으로 검사를 진행한다고 했을 때 발생하는 **3가지 경우의 수**를 고려
1. **높이의 차가 없을 때 (동일할 때)**  
2. **내려갈 때**  
   - 반대 방향으로 검사할 때 걸릴 예정이므로 따로 처리 X  
3. **현재 높이보다 1 클 때**  
   - 경사로를 놓을 **공간이 충분해야 하고**, 기존에 놓은 경사로가 없을 때만 새로운 경사로를 놓을 수 있음  
   - 해당 조건에 부합하지 않으면 `False` 반환
