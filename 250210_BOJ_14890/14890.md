# BOJ 14890 경사로 문제
- 경사로는 left 경사로 / right 경사로 2가지로 나뉨
- `count`는 현재 높이가 얼마나 지속되었는지 (몇 칸인지) 파악하는 변수
- `prev`는 이전 길의 높이 정보


0. 이어지는 길의 높이 차이가 `1`보다 큰 경우 **경사로 설치 불가능**

<br>

1. `right 경사로`는 이전 길이 현재 길보다 낮을 때 사용
- 바로 파악 가능
    - `count < l` 이면 설치 불가능
    - `left == True`인 경우, `left 경사로` + `right 경사로` 설치해야 함
        - `count < 2 * l` 이면 설치 불가

<br>

2. `left 경사로`는 이전 길이 현재 길보다 높을 때 사용   
- 바로 파악 불가능
    - `left` 변수를 True로 두고, 높이가 다른 길이 나타났을 때, `left 경사로` 설치 가능한지 판단

<br>

3. 길을 다 순회했을 때, `left == True`이면 경사로 설치 가능 여부 판단

<br>

4. 경사로 설치 가능한 경우, `result += 1`
