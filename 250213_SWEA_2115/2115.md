# SWEA 2115 문제 풀이
### 조건
1. `N x N`개의 벌통 (정사각형 모양)
    - `3 ≤ N ≤ 10`
    - 벌꿀을 최대한 많이 채취해 최대 수익을 벌자

<br>

2. 일꾼 2명
    - 가로로 같은 줄에 있는 벌통만 채취 가능
    - 일꾼은 같은 벌통 채취 못함
    - 채취할 수 있는 벌통은 m개, `1 ≤ m ≤ 5`
    - 각 일꾼이 채취할 수 있는 꿀의 최대 양은 c, `10 ≤ c ≤ 30`
    - 벌통에서 일부의 꿀만 채취 불가능, 항상 벌통 안의 모든 꿀을 채취해야 함

<br>

3. 꿀의 가치
    - 꿀의 가치는 꿀의 양의 제곱

---
## ✅ 풀이
1. 가로 줄에 원소가 `m`개인 `sublist`에서 꿀의 가치의 최대치를 미리 구하자
    - combination 사용, 꿀의 양이 `c`를 넘지 않으면서 꿀의 가치는 `최대`가 되도록 선택   
    ➡️ `arr`에 삽입

<br>

2. `arr`을 순회하면서 두 일꾼의 꿀의 가치의 합이 최대인 것을 찾자
    - `row = i` 인 지점에서 `col = j` 인 꿀을 선택했으면
    - `j - m ≤ index ≤ j + m` 사이의 `column index`는 선택하면 안됨   
    ➡️같은 벌통은 채취하면 안되는 조건 때문에

### 이런 식으로 순회하면서 일꾼 2명이 각각 채취한 꿀통의 합이 최대가 되도록 선택
