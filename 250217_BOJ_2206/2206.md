# 벽 부수고 이동하기

## 유형

- BFS

## 고려사항

### 탐색

- 전에 수업시간에 풀었던 보급로 문제랑 비슷한 느낌
- 벽을 한번만 부술 수 있어 삼차원 배열로 만들어 벽을 부순 상태, 아닌 상태 나눠 최단거리 확인
- 큐에 들어가는 조건은 두가지
    - 탐색하는 노드가 벽이고 아직 벽을 부순적이 없는 경우
    - 탐색하는 노드가 벽이 아니고 아직 방문하지 않은 경우
- 큐가 비어있을때까지 진행

### 의문 사항

dfs로 처음에 짯는데 메모리 제한 걸림

이거 로직은 맞는건가

```python
dirs = [
    (0, 1),
    (1, 0),
    (-1, 0),
    (0, -1)
]

def dfs(cur, path, broken):
    global arr, visited, result
    
    if cur == (n - 1, m - 1):
        result = min(result, path)
        return

    for dir in dirs:
        nx, ny = cur[0] + dir[0], cur[1] + dir[1]
        if 0 <= nx < n and 0 <= ny < m and visited[nx][ny] == 0:
            if arr[nx][ny]:
                if broken:
                    continue
                else:
                    visited[nx][ny] = 1
                    dfs((nx, ny), path + 1, 1)
                    visited[nx][ny] = 0
            else:
                visited[nx][ny] = 1
                dfs((nx, ny), path + 1, broken)
                visited[nx][ny] = 0

n, m = map(int, input().split())

arr = [list(map(int, str(input()))) for _ in range(n)]

visited = [[0] * m for _ in range(n)]

visited[0][0] = 1
result = 999999999
dfs((0, 0), 0, 0)

if result == 999999999:
    result = -1
else:
    result += 1
print(result)
```
