# Algorithm Study

### Master Branch
- 코드 리뷰 결과 **최적의 코드**만 저장하는 Branch
- 🚫 개인은 절대 건들지 말 것 🚫
- Pull Request를 통해서만 update

### Problem Branch
- 문제 출제자는 Problem Branch에 문제 출제
- 스터디원들은 Problem Branch를 pull해서 문제 풉니다
<br>

**아래 형식으로 빈 파일들을 폴더에 넣어서 출제해주세요.**
- 폴더 이름
    - 날짜_문제사이트_문제번호
- 폴더 내 파일들
    - 날짜_문제사이트_문제번호.py
    - 날짜_문제사이트_문제번호.cpp
    - explain.md

### Member Branch
- 개인별로 원격 저장소 Branch 생성
- 자신이 푼 코드 + 코드 설명은 개인 원격 Branch에 push

## 📜기본 룰

- 문제는 주 7일 출제
    
    | 요일 | **출제자** |
    | :---: | :---: |
    | Mon | 최혁진 |
    | Tue | 류명진 |
    | Wed | 조정래 |
    | Thu | 김형석 |
    | Fri | 김영우 |
    | Sat | 문소윤 |
    | Sun | 양지웅 |

- 7일 중 **4일 이상** 문제 해결 필수 ( 4일 미만 참여한 경우 벌금 )
- 해결 코드 + 코드 설명(.md) 작성
- 문제 출제는 구성원 모두 돌아가며 출제
- 언어 : C++ or Python

## 🤔문제 출제

- 제출 마감 시간은 익일 02:00로 설정
- 백준 기준 실버X~골드X, SWEA 기준 D3~D5
- 유형 자율

## 📚오프라인 스터디

- 기본적인 문제 풀이는 노션 인증을 기본으로 함
- **희망자**에 한해 오프라인 스터디 진행
- 코드 리뷰 또는문제 풀이 진행 예정

## 💵벌금

- 못 푸는 것이 아닌, 안 푸는 것에 대한 벌금
- 못 풀었을 때 시도했던 코드 혹은 필기 인증으로 대체
- 주 4일 이상 참여하지 않았을 경우 벌금 부과
    - 부족한 일수 * 3000원
    - 예시) 한 주에 문제를 2일만 푼 경우: (4일 - 2일) * 3000원 = 6000원
- 아프거나 피치 못한 사정이 있을 경우 연락 남기기
- 모인 벌금은 월말에 1/N 하거나 회식(저녁 식사)에 사용 (협의 예정)
